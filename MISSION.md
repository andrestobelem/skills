# Mission

## English

Create and maintain focused skills that give agents useful instructions for specific tasks.

For each skill, we:

- Keep the English and Spanish versions aligned.
- Use clear and direct language.
- Define guidance that agents can apply in practice.
- Improve the skill when experience shows a better method.

## Español

Crear y mantener habilidades específicas que den a los agentes instrucciones útiles para tareas concretas.

Para cada habilidad:

- Mantenemos alineadas las versiones en inglés y español.
- Usamos un lenguaje claro y directo.
- Definimos pautas que los agentes puedan aplicar en la práctica.
- Mejoramos la habilidad cuando la experiencia muestra un método mejor.
