# Constitution

## English

### 1. Purpose

This repository provides clear, practical, and reusable skills for agents. Each skill must help an agent complete a defined task.

### 2. Core principles

All skills must follow these principles:

- **Clarity:** Use direct instructions and consistent terms.
- **Practical value:** Give guidance that an agent can apply to a real task.
- **Simplicity:** Include only information that supports the task.
- **Consistency:** Keep the structure and guidance coherent across the repository.
- **Continuous improvement:** Update a skill when evidence shows a better method.

### 3. Language

Each skill must have an English version and a Spanish version. Both versions must have the same intent and requirements. English content must follow ASD Simplified Technical English (ASD-STE100).

### 4. Skill design

Each skill must:

- Have a clear name and purpose.
- Define instructions that an agent can follow.
- Use examples only when they improve understanding.
- Avoid unnecessary duplication and complexity.
- Keep related guidance together.

### 5. Changes

Each change must be focused and reviewable. Commits must follow Conventional Commits, include a scope, and remain atomic. Commit messages must not attribute work to agents.

Changes to this constitution must keep the English and Spanish sections aligned.

## Español

### 1. Propósito

Este repositorio proporciona habilidades claras, prácticas y reutilizables para agentes. Cada habilidad debe ayudar a un agente a completar una tarea definida.

### 2. Principios fundamentales

Todas las habilidades deben cumplir estos principios:

- **Claridad:** Usar instrucciones directas y términos uniformes.
- **Valor práctico:** Dar pautas que un agente pueda aplicar a una tarea real.
- **Simplicidad:** Incluir solo información que contribuya a la tarea.
- **Uniformidad:** Mantener coherentes la estructura y las pautas en todo el repositorio.
- **Mejora continua:** Actualizar una habilidad cuando la evidencia muestre un método mejor.

### 3. Idioma

Cada habilidad debe tener una versión en inglés y otra en español. Ambas versiones deben tener la misma intención y los mismos requisitos. El contenido en inglés debe cumplir con el Inglés Técnico Simplificado de ASD (ASD-STE100).

### 4. Diseño de las habilidades

Cada habilidad debe:

- Tener un nombre y un propósito claros.
- Definir instrucciones que un agente pueda seguir.
- Usar ejemplos solo cuando mejoren la comprensión.
- Evitar la duplicación y la complejidad innecesarias.
- Mantener juntas las pautas relacionadas.

### 5. Cambios

Cada cambio debe ser específico y fácil de revisar. Los commits deben seguir Conventional Commits, incluir un alcance y ser atómicos. Los mensajes de commit no deben atribuir el trabajo a agentes.

Los cambios a esta constitución deben mantener alineadas las secciones en inglés y español.
