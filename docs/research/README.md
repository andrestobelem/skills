# Research

## English

This directory contains research that supports the design and development of repository skills and practices.

For each research document, identify the sources, record the relevant findings, and explain how the findings affect the repository.

## Español

En cada documento de investigación, identificar las fuentes, registrar los hallazgos pertinentes y explicar cómo afectan al repositorio.
