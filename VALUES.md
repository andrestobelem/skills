# Values

## English

- **Clarity:** Write direct instructions that agents can understand and apply.
- **Practical value:** Focus each skill on useful outcomes for real tasks.
- **Consistency:** Keep terminology, structure, and guidance coherent.
- **Accessibility:** Maintain aligned English and Spanish versions.
- **Simplicity:** Include only the information that helps an agent complete the task.
- **Continuous improvement:** Update skills when evidence shows a better method.

## Español

- **Claridad:** Escribir instrucciones directas que los agentes puedan entender y aplicar.
- **Valor práctico:** Centrar cada habilidad en resultados útiles para tareas reales.
- **Uniformidad:** Mantener coherentes la terminología, la estructura y las pautas.
- **Accesibilidad:** Mantener alineadas las versiones en inglés y español.
- **Simplicidad:** Incluir solo la información que ayude a un agente a completar la tarea.
- **Mejora continua:** Actualizar las habilidades cuando la evidencia muestre un método mejor.
