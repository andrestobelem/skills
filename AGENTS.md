# Repository instructions

- Before you plan a change, read `CONSTITUTION.md`, `MISSION.md`, `VALUES.md`, `VISION.md`, and `DEVELOPMENT.md`.
- Use the alignment workflow and the definition of done in `DEVELOPMENT.md`.
- If a request conflicts with the constitution or a core value, stop and explain the conflict. Do not silently bypass it.
- Keep each skill in English and Spanish. Keep both versions aligned.
- Write English content according to ASD Simplified Technical English (ASD-STE100).
- Use Conventional Commits with a scope. Make each commit atomic.
- Do not attribute commits to agents, including with `Co-authored-by` trailers.
