# Learning principles

- **Iteration:** Work in short cycles. Review each result and adjust the direction.
- **Feedback:** Get fast, reliable information about the code and its usefulness.
- **Incrementalism:** Build the system in small increments. Evaluate each increment separately.
- **Experimentation:** State a hypothesis and design a test to check it.
- **Empiricism:** Make decisions from observations and measurements. Change a decision when the evidence supports the change.
