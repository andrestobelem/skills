# Skills

## Direction and governance

- [Constitution](CONSTITUTION.md): mandatory and durable repository rules.
- [Mission](MISSION.md): the reason that the repository exists.

- [Vision](VISION.md): the future state that guides progress.
- [Development](DEVELOPMENT.md): the operating workflow that applies these documents to agent work.
